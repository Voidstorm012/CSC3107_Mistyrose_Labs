# CSC3107 Week 3: Exploring ggplot2

This repository contains the implementation of the Week 3 lab assignment for CSC3107, focusing on data visualization using ggplot2 in R.

## Overview

The lab explores various visualization techniques in ggplot2 through two main tasks:

1. **Visualizing the Distribution of Quantitative Data**: Analysis of bill lengths of Pygoscelis penguins using various visualization techniques including scatter plots, jitter plots, bee-swarm plots, violin plots, frequency polygons, and faceted plots.

2. **Mitigating Overplotting**: Demonstration of techniques to handle overplotting in scatter plots using a flight price dataset, including alpha transparency, jittering, 2D density plots, and smoothing interpolations.

## Datasets

The lab uses two datasets:

1. **Palmer Penguins**: A dataset containing measurements of three penguin species (Adelie, Chinstrap, and Gentoo) from the Palmer Archipelago, Antarctica. This dataset is included in the `palmerpenguins` R package.

2. **Flight Price Dataset**: A dataset containing information about flight prices, airlines, routes, and other attributes. This dataset was obtained from [Kaggle](https://www.kaggle.com/datasets/shubhambathwal/flight-price-prediction/data).

## Requirements

To run the code in this lab, you need:

- R (version 4.0.0 or higher recommended)
- RStudio (for running the Quarto document)
- The following R packages:
  - tidyverse
  - palmerpenguins
  - ggbeeswarm
  - broom
  - readr

## How to Run

1. Clone this repository
2. Open the `Lab3.qmd` file in RStudio
3. Make sure all required packages are installed
4. Run the code chunks in the Quarto document

## File Structure

- `Lab3.qmd`: The main Quarto document containing all code and explanations
- `Clean_Dataset.csv`: The flight price dataset used for the overplotting demonstration
