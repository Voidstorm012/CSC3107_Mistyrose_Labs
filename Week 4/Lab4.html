1.3 Mosaic Plot

When working with two categorical variables, such as class and survival, mosaic plots provide an alternative to segmented bar charts. Use the geom_mosaic() function from the ggmosaic package to create a mosaic plot of the data in titanic.

library(ggplot2)
library(ggmosaic)
library(dplyr)

# Base plot
p <- ggplot(data = titanic) +
  geom_mosaic(aes(x = product(class), fill = survived, weight = 1)) +
  scale_fill_manual(values = c("FALSE" = "coral", "TRUE" = "lightblue")) +
  labs(
    title = "Titanic Travelers by Class and Survival",
    x = "Class",
    y = "Survived",

1.4 Pros and Cons of Mosaic Plots

State one advantage and one disadvantage of using the mosaic plot instead of the dodged bar chart for the Titanic data.

Advantage: The mosaic plot effectively shows both the relative proportions of each class among all travelers (width of each section) and the survival rate within each class (height of colored segments), providing a comprehensive view of both marginal and conditional distributions in a single visualization.

Disadvantage: The mosaic plot makes it more difficult to compare exact counts between groups compared to the dodged bar chart, as the varying widths of the class sections make direct visual comparison of survival numbers across classes less intuitive.

Discussion:

Advantages: - Standardized comparison: The stacked percentage bar chart allows for direct comparison of survival rates across classes since all bars reach 100%, making it easy to see that 1st class had the highest survival rate (~62%) while crew had the lowest (~24%). - Clear proportional relationships: The visualization immediately shows the proportion of survivors vs. non-survivors within each class, making survival rates the primary focus rather than absolute numbers. - Intuitive interpretation: Percentages are easily understood and the stacked format clearly shows the complementary nature of survival/non-survival outcomes.

Limitations: - Loss of absolute numbers: Unlike bar charts, this visualization doesn’t show the actual number of people in each class, which could be important for understanding the scale of the tragedy. - Less detailed than mosaic plots: While easier to read than mosaic plots, it doesn’t show the relative size of each class in the overall population as effectively as the mosaic plot’s varying widths. - Binary focus: The stacked format works well for binary outcomes but would be less effective if there were more than two survival categories to display.

2 Water Potability Analysis

2.1 Data Source and Description

Data URL: https://www.kaggle.com/datasets/adityakadiwal/water-potability/data

The water potability dataset contains water quality measurements that determine the safety of water for human consumption. This dataset was collected from various water sources and includes 9 water quality parameters measured across 3,276 different water samples. The key variables include:

  • pH: Acidity/alkalinity level of water (normal range: 6.5-8.5)
  • Hardness: Calcium and magnesium mineral content (mg/L)
  • Solids: Total dissolved solids concentration (mg/L)
  • Chloramines: Disinfectant concentration (mg/L)
  • Sulfate: Sulfate ion concentration (mg/L)
  • Conductivity: Electrical conductivity (μS/cm)
  • Organic_carbon: Organic carbon content (mg/L)
  • Trihalomethanes: Byproduct concentration from chlorination (μg/L)
  • Turbidity: Cloudiness measure (NTU)
  • Potability: Binary outcome (0 = not potable, 1 = potable)

2.2 Water Quality Visualization

The following scatter plot visualizes the relationship between pH levels and conductivity, with additional aesthetic mappings for sulfate content and water potability:

library(ggplot2)
library(dplyr)

# Remove rows with missing values for the variables we're plotting
water_clean <- water %>%
  filter(!is.na(ph), !is.na(Conductivity), !is.na(Sulfate), !is.na(Potability))

# Create the visualization
ggplot(water_clean, aes(x = ph, y = Conductivity)) +
  geom_point(aes(color = factor(Potability), size = Sulfate), alpha = 0.7) +
  scale_color_manual(
    values = c("0" = "coral", "1" = "lightblue"),
    labels = c("0" = "Not Potable", "1" = "Potable")
  ) +
  scale_size_continuous(
    range = c(1, 4),
    guide = guide_legend(override.aes = list(alpha = 1))
  ) +
  labs(
    title = "Water Quality Assessment: pH vs Conductivity",
    subtitle = "Point size represents sulfate concentration, color indicates potability",
    x = "pH Level",
    y = "Conductivity (μS/cm)",
    color = "Water Potability",
    size = "Sulfate (mg/L)",
    caption = "Source: Kaggle Water Potability Dataset"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(hjust = 0.5, size = 14, face = "bold"),
    plot.subtitle = element_text(hjust = 0.5, size = 12),
    axis.text = element_text(size = 11),
    axis.title = element_text(size = 12),
    legend.position = "right",
    plot.caption = element_text(hjust = 0.5)
  ) +
  facet_wrap(~factor(Potability, labels = c("Not Potable", "Potable")), ncol = 2)

2.3 Aesthetic Mapping Justification

Color Mapping (Potability): We mapped the potability variable to the color aesthetic because this is a categorical binary variable that represents the most important outcome of interest. Color is an appropriate choice for nominal data as it allows for immediate visual distinction between potable and non-potable water samples. The contrasting colors (coral for non-potable, light blue for potable) follow perceptual best practices by being easily distinguishable and avoiding problematic color combinations for colorblind users.

Size Mapping (Sulfate): We mapped the sulfate concentration to the size aesthetic because sulfate is a continuous quantitative variable where larger values represent higher concentrations. Size is semantically appropriate for extensive variables like concentration - when sulfate content increases, the visual representation (point size) proportionally increases. This follows the principle that visual properties should correspond to the mathematical properties of the data, making larger sulfate concentrations immediately apparent through larger points.

2.4 Key Insights

The visualization reveals that water potability is not strongly determined by pH and conductivity levels alone, as both potable and non-potable water samples show considerable overlap across the pH-conductivity space. However, there appears to be a slight concentration of non-potable samples in the higher conductivity ranges (above 400 μS/cm), suggesting that extremely high conductivity may be associated with water safety concerns. The sulfate concentrations (represented by point size) vary considerably within both potable and non-potable categories, indicating that sulfate levels alone are not a definitive predictor of water safety, but rather that water potability depends on a complex interaction of multiple chemical parameters.
